# secendthink

A Codex plugin that improves your request into a clear, thorough prompt and immediately carries it out in the same task. No copy-paste step is needed.

## Use

Invoke `/secendthink` or `/st` with your request. Dollar mentions (`$secendthink` or `$st`) are also supported where your host supports them.

Example: `/st plan my portfolio website`

The plugin uses your currently selected model, keeps your original constraints and permissions, and returns the completed work. Ask for **only the prompt** when you want a reusable prompt instead, or ask to **show the prompt and run it** to receive both.

After updating an installed copy, start a new task to pick up the changes.
